# Opentrons

CFB Opentrons repo

## Folder Structure

### OT2/
Protocols in active use for the OT-2. These should be working with current software versions.

### Flex/
Protocols in active use for the Flex. These should be working with current software versions.

### Utility_and_Testing/
Scripts for calibration and testing.

### Archive/
Scripts that are not verified and may not be compatible with newer software versions. These are preserved for posterity.
